Hostinger VPS Backups

Hostinger VPS Backups is a personal, non-commercial utility for securely backing up selected files from a privately managed server to the owner's Google Drive account.

The intended workflow uses Restic to encrypt backups before upload and Rclone to transfer encrypted backup files using the Google Drive API. The application requests the drive.file permission, limited to files created by or explicitly opened with the application.

This utility is intended for use by its owner, not offered as a public backup service. It is currently being configured; the automated backup system is not yet operational.

Read the Privacy Policy for details on data handling and permissions.
