Privacy Policy

Effective date: October 11, 2026.

Hostinger VPS Backups is a personal project, intended solely for use by its owner. It is not a service offered to outside users.

Purpose

The application is intended to store encrypted backups of files selected by the owner in the owner's Google Drive account.

Google Drive permissions

The application requests the Google Drive drive.file scope to manage only files created by or explicitly made available to the application. It does not request access to every file in the account.

Data handling

Backup files are intended to be encrypted locally before upload. Authorized backup software may create, list, retrieve or delete those encrypted files under the owner's control. Google Drive stores the resulting encrypted files according to Google's applicable terms.

Sharing and retention

The owner does not sell backup data or intentionally share it with third parties. The owner controls retention and may delete backup files or revoke the application's authorization through Google account settings.

Website

This website contains only information about the personal project. It does not have sign-up forms or collect personal information through forms. GitHub Pages hosts the website and may process standard access information under GitHub's privacy terms.

Contact

For questions about this personal project, use the GitHub repository.
